# Focused roadmap

- Shipped in 0.1.2: repeated-input group comparison, call/failure counts, search and source-step navigation
- Next: per-turn comparison with explicit missing-usage handling
- Then: explicitly versioned adapters for other exported agent formats, based on public fixtures
- Later: configurable large-output thresholds

Not planned: live model gateway, agent memory, automated success scoring or estimated token savings. Improvements should answer a concrete debugging question with evidence in the imported file.
